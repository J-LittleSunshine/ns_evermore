```text

+ explicit representation/editability qualification
+ non-destructive preservation of legal semantics that cannot be edited visually
```

# 7. W2 Internal Architecture Responsibilities

## W2-R01 — Authoring Context & Session Provenance

Owns the Web-origin Authoring Session occurrence and Authoring Context projection used to qualify one bounded authoring interaction. It preserves Tenant, Organization, Principal, authenticated identity evidence reference, authorization/policy/trust context references, locale/timezone presentation context, privacy/redaction qualification and interaction/session provenance without becoming any of those authorities.

```text
Authoring Session != Draft
Authoring Session != Definition Revision
Browser Session != Authoritative Session Truth
Authenticated Principal != Authorized Editor automatically
Editor Affordance != Permission
```

A Draft may outlive one session; one session may interact with multiple drafts only when each interaction remains separately correlated. No browser/session identifier format is selected.

## W2-R02 — Authoritative Definition Reference & Domain Qualification

Owns W2 correlation to the authoritative Definition domain/type/identity/revision and receiving authority. It does not own the referenced semantics.

Stable correlation includes, where applicable:

```text
Definition Domain
Definition Type / semantic family qualification
Authoritative Definition Identity
Authoritative Definition Revision
Definition Authority / SoT reference
Tenant / governance applicability
source-owner provenance
```

`Domain Qualification` is not a lowest-common-denominator domain model. Domain-specific semantics remain S5/S6/S7/A1-owned.

## W2-R03 — Authoring Projection & Projection Revision

Owns the Web visual Authoring Projection and its projection revision/evolution, including which authoritative revision/source evidence it represents and the currentness/limitation/redaction qualifications applied to that projection.

```text
Authoritative Definition Revision != Authoring Projection
Authoring Projection Revision != Canonical Definition Revision
Projection Fresh != Authority
Projection Stale != Source Revision mutated
```

A projection may be reconstructed or re-presented without changing the authoritative Definition. Material transformation provenance is retained.

## W2-R04 — Local Draft Identity, Evolution & Revision-base Binding

Owns W2-local Draft Identity, Draft Evolution lineage and binding to an exact canonical base revision when editing an existing Definition.

```text
Local Draft != Authoring Projection
Local Draft != Canonical Definition Revision
Draft Base Revision != Current Authoritative Revision automatically
Draft Evolution != Canonical Revision lineage
```

For a genuinely new Definition candidate, absence of a prior canonical base is explicit and is not treated as an unknown existing base. New draft evolution does not overwrite earlier draft lineage; branches/concurrent draft lines may coexist without a winner rule.

## W2-R05 — Governed Edit Intent & Governed Change Intent

Owns Web-origin authoring intent semantics.

- `Edit Intent` expresses a bounded proposed local edit against a Draft/projection context.
- `Change Intent` expresses the governed semantic change the author intends to submit to the receiving Definition Authority.

They may correlate but are not collapsed:

```text
Edit Intent != Draft Revision
Change Intent != Canonical Revision
Edit Intent != Submission
Change Intent != Acceptance
```

W2 may block a destructive edit where a construct is non-editable/representation-limited; that block is a W2 authoring safety behavior, not a domain validation judgment.

## W2-R06 — Authoring Submission Occurrence & Receiving Authority Correlation

Owns the Web fact that a governed authoring/change submission occurred and its correlation to the intended receiving Definition Authority and exact draft/base context.

```text

Submission != Applicability
Submission != Validation
Submission != Canonicalization
Submission != Acceptance
```

Receiving S5/S6/S7/A1 authority owns domain-side intake/applicability/canonical outcome. W2 preserves submission identity/history and later source evidence without rewriting the original submission occurrence.
